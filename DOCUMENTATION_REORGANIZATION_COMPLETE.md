## 📝 Aturan Baru

### Konvensi Penamaan
```
Format: [KATEGORI]_[DESKRIPSI]_[TIPE].md

Contoh:
✅ FASE_10_COMPLETE.md
✅ TASK_10_IMPLEMENTATION_SUMMARY.md
✅ QUICK_START_GUIDE.md
```

### Peletakan File
```
- Fase/Milestone     → docs/FASE_[N]_COMPLETE.md
- Implementasi       → docs/reports/TASK_[N]_*.md
- Panduan            → docs/guides/[TOPIC]_GUIDE.md
- Modul Spesifik     → docs/[module]/[MODULE]_*.md
- Dokumentasi Lama   → docs/archive/[category]/
```

### Workflow
```
1. Tentukan jenis dokumentasi
2. Gunakan template yang sesuai
3. Ikuti konvensi penamaan
4. Tempatkan di folder yang benar
5. Update README folder jika perlu
```
