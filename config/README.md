# Firebase Service Account Credentials

Tempatkan file kunci akun layanan Firebase Anda (Firebase Service Account Key) di direktori ini dengan nama file:
`firebase-service-account.json`

## Cara Mendapatkan File Ini:
1. Buka [Firebase Console](https://console.firebase.google.com/).
2. Pilih proyek Firebase Anda.
3. Klik ikon Gear/Settings (Setelan Proyek) di bagian kiri atas.
4. Pilih tab **Service Accounts** (Akun Layanan).
5. Klik tombol **Generate New Private Key** (Buat Kunci Privat Baru).
6. File JSON akan terunduh secara otomatis.
7. Ubah nama file tersebut menjadi `firebase-service-account.json` dan letakkan di dalam folder `config` ini.
