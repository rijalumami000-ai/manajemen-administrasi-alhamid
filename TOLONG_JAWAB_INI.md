## Cara Cek Console Browser

1. Buka halaman Santri
2. Tekan **F12** di keyboard
3. Klik tab **Console**
4. Lihat apakah ada tulisan merah (error)
5. Screenshot dan kirim ke saya

---

## Cara Cek Network Tab

1. Buka halaman Santri
2. Tekan **F12** di keyboard
3. Klik tab **Network**
4. Coba tambah santri atau migrasi
5. Lihat request yang muncul
6. Klik request tersebut
7. Lihat tab "Response"
8. Screenshot dan kirim ke saya
