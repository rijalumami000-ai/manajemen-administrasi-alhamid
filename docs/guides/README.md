## 📝 Menambah Panduan Baru

Untuk menambah panduan baru:

1. **Format Nama:** `[TOPIK]_GUIDE.md` atau `[TOPIK]_CHECKLIST.md`
2. **Gunakan Template:**
   ```markdown
   # [Judul Panduan]
   
   ## Overview
   [Deskripsi singkat]
   
   ## Prerequisites
   - Requirement 1
   - Requirement 2
   
   ## Step-by-Step Guide
   ### 1. [Step 1]
   [Detail]
   
   ### 2. [Step 2]
   [Detail]
   
   ## Troubleshooting
   [Common issues dan solusi]
   
   ## References
   [Link ke dokumentasi terkait]
   ```

3. **Update README ini** dengan link ke panduan baru

## 🎯 Jenis Panduan

### Guide (Panduan)
Panduan step-by-step untuk melakukan sesuatu:
- Fokus pada "how-to"
- Berisi langkah-langkah konkret
- Contoh: QUICK_START_GUIDE.md

### Checklist
Daftar periksa untuk memastikan semua langkah dilakukan:
- Format checklist dengan checkbox
- Untuk proses yang berulang
- Contoh: MANUAL_TESTING_CHECKLIST.md

### Reference (Referensi)
Dokumentasi referensi cepat:
- Informasi ringkas
- Untuk lookup cepat
- Contoh: QUICK_REFERENCE_MULTI_AGENT.md

### Workflow
Alur kerja dan proses:
- Menjelaskan proses end-to-end
- Diagram dan flowchart
- Contoh: MULTI_AGENT_WORKFLOW.md
