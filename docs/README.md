## 🔍 Mencari Dokumentasi

### Berdasarkan Topik
- **Setup & Installation** → DEVELOPMENT_GUIDE.md
- **Deployment** → DEPLOYMENT_GUIDE.md
- **Testing** → TESTING_CHECKLIST.md, guides/MANUAL_TESTING_CHECKLIST.md
- **Modul Alumni** → alumni/
- **Multi-Agent** → guides/MULTI_AGENT_WORKFLOW.md
- **Validasi** → guides/VALIDATION_PATTERN_GUIDE.md

### Berdasarkan Task/Prioritas
Lihat folder `reports/` untuk dokumentasi task spesifik:
- TASK_[N]_IMPLEMENTATION_SUMMARY.md
- PRIORITAS_[N]_COMPLETE.md

## 📞 Kontak & Kontribusi

Untuk pertanyaan atau kontribusi dokumentasi:
1. Ikuti panduan di DOCUMENTATION_STRUCTURE_GUIDE.md
2. Pastikan dokumentasi ditempatkan di folder yang benar
3. Gunakan template yang tersedia
4. Update PROJECT_STATUS.md jika perlu
